# 小菠萝的工作台 v0.1.1 更新日志

## 新增内容

- 在线书城内置「番茄小说」与「10000txt」两个书城。
- 在线书城支持自定义添加小说网址，自动补全 `https://`，可删除自定义书城。
- 书架分类标签支持删除；删除分类后，原分类下的书籍自动改为「未分类」。
- 收藏状态更明显：收藏后按钮变为暖橙色，书签图标纵向拉长并带轻微阴影过渡。

## 修复问题

- 修复已有用户数据目录中「番茄小说」等内置书城不显示的问题，现在会自动补齐内置书城。
- 修复新增分类后无法删除分类标签的问题。
- 修复收藏按钮选中前后视觉区分不明显的问题。

## 构建说明

- 安装包：`小菠萝的工作台-0.1.1-安装包.exe`
- 便携版：`小菠萝的工作台-0.1.1-portable.exe`
