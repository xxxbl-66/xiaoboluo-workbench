# v0.2.0

发布日期：2026 年 9 月 27 日。

本版整理当前工作空间与连续工作功能，并保留 v0.1.3 的保存和会话恢复修复。

## 工作空间与连续工作

- “今天”页面聚焦当前和最近工作、下一步以及快速入口。
- 工作空间统一组织任务、长期目标、便签、文件、收藏、应用和工作流。
- 完成事项保存结束时的标题快照，历史与当前任务分别读取。
- 恢复工作先创建新的会话，再按配置运行默认工作流。
- 工作流支持有序打开应用、文件、文件夹和 HTTP(S) 网页，逐步显示成功或失败。
- 工作空间快速切换时检查响应归属，避免旧内容进入新空间。
- 改善工作流结果展示、资源保存反馈与工作历史入口。

## 保留已有修复

- 保留会话关闭请求的对应关系，重复关闭或旧回执不能绕过当前确认。
- 已显示的关闭确认不因短时间未作选择而强制退出。
- 未结束会话的结束与有效时长校正在一次写入中完成，输入无效时保留原会话。
- 保留便签即时输入、复盘保存回执和自定义铃声失败反馈修复。
- 保留未结束会话的恢复提示，以及备份导入前恢复点检查。

## 发布包

- 提供 Windows 10/11 x64 安装版和便携版，内置版本号均为 0.2.0。
- README 更新功能说明、当前界面截图、使用步骤、数据位置和下载链接。
- 核心数据仍保存在本机，默认沿用历史数据目录。升级前建议导出备份。

工作流打开的是资源入口，不恢复第三方程序的内部状态；结构化备份不包含全部外部资料文件。
